# Awesome Local Web Development Environments & Stacks

A curated list of modern XAMPP alternatives, local web server stacks, virtualization platforms, and database tools.

## Local Web Development Stacks

* [WampServer](https://sourceforge.net/projects/wampserver/) – Classic Windows web development environment providing Apache, PHP, MySQL, and phpMyAdmin. *(Free · Open Source)*
* [WordPress Studio](https://developer.wordpress.com/studio/) – Modern, lightweight local WordPress environment with shareable preview sites and instant setup. *(Free · Open Source - GPL-2.0)*
* [The Uniform Server](https://www.uniformserver.com/) – Lightweight, portable WAMP package that runs without installation, even from USB drives. *(Free · Open Source)*
* [BitNami Application Stacks](https://bitnami.com/stacks) – Self-contained installers for launching open-source apps alongside their required web and database stacks. *(Free · Open Source)*
* [DDEV](https://github.com/ddev/ddev) – Docker-based local development environment for PHP, Python, and Node.js with per-project version control. *(Free · Open Source - Apache-2.0)*
* [Laragon](https://github.com/leokhoa/laragon) – Fast, lightweight LAMP stack with automatic virtual hosts, Redis, and Memcached support. *(Open Source · Pay once / Subscription)*
* [Lando](https://github.com/lando/lando) – Flexible containerized development and DevOps tool configured via simple Git-tracked config files. *(Free · Open Source - MIT)*
* [UwAmp](https://www.uwamp.com/en/) – WAMP stack featuring a real-time CPU monitor, multi-version PHP selector, and U3 portable drive support. *(Free · Proprietary)*
* [Laravel Homestead](https://laravel.com/framework/docs/homestead) – Pre-packaged official Vagrant box bundling Nginx, PHP, MySQL, Redis, and essential services. *(Free · Open Source - MIT)*
* [EasyPHP](https://www.easyphp.org/) – Portable Windows-based WAMP environment for local development and USB deployment. *(Freemium · Open Source)*
* [Fenix Web Server](https://github.com/coreybutler/fenix) – Visual desktop web server focused on static site serving and team sharing. *(Free · Open Source)*
* [WinNMP](https://github.com/givemesite/GMS-AT-OpenSource.V1.2/blob/master/HOW-TOS.md) – Portable Nginx, MariaDB, and PHP stack for Windows with automated configuration preservation. *(Free · Proprietary)*
* [Open Server Panel](https://ospanel.io/en/) – Feature-packed Windows stack with Apache, Nginx, PostgreSQL, MongoDB, and multi-version switching. *(Free · Proprietary)*
* [EnvKit](https://envkit.net/) – Tray-based local stack supporting Nginx, Apache, multiple PHP versions, Node, databases, and built-in AI MCP support. *(Free · Proprietary)*
* [WnMp (SourceForge)](https://sourceforge.net/projects/w-nmp/) – Windows, Nginx, MariaDB, and PHP bundle. <span style="color:red">**[Discontinued - Last updated January 2018]**</span> *(Free · Open Source)*
* [Abyss Web Server](https://aprelium.com/) – Compact, low-footprint web server with remote web configuration, native ASP.NET, and SSL support. *(Freemium · Proprietary)*
* [VertrigoServ](https://sourceforge.net/projects/vertrigo/) – Convenient all-in-one Windows installer for Apache, PHP, MySQL, and Xdebug. *(Free Personal · Proprietary)*
* [WPN-XM](https://github.com/WPN-XM/WPN-XM) – Windows Nginx, PHP, and MariaDB stack with tray management. <span style="color:red">**[Discontinued - Last release August 2015]**</span> *(Free · Open Source)*
* [Laravel Valet](https://github.com/laravel/valet) – Minimalist Mac-only development environment running Nginx and DnsMasq with negligible memory footprint. *(Free · Open Source - MIT)*
* [Acquia Dev Desktop](https://docs.acquia.com/resources/acquia-dev-desktop-folders-and-files) – Tailored Drupal development stack. <span style="color:red">**[Discontinued - Support ended June 2021]**</span> *(Free · Open Source)*
* [ForgeKit](https://forgekit.tools/) – Windows-native environment running per-site isolated PHP versions, databases, and Nginx/Apache without Docker. *(Free · Proprietary)*
* [SecureWAMP](https://securewamp.org/) – GUI-administered WAMP server with dev and production modes. <span style="color:red">**[Discontinued - Last updated 2012]**</span> *(Free · Open Source)*
* [WNMP (GitHub)](https://github.com/x64architecture/wnmp) – Lightweight Nginx, MariaDB, and PHP launcher for legacy Windows. <span style="color:red">**[Discontinued]**</span> *(Free · Open Source - GPL-3.0)*
* [Winginx](https://winginx.com/en/) – Local Windows stack for PHP and Node.js development. <span style="color:red">**[Discontinued - Last updated May 2017]**</span> *(Free · Proprietary)*
* [ramp+](https://rampp.app/) – Service manager supporting Apache, Nginx, PHP, Node.js, databases, and development utilities like Mailpit. *(Free · Proprietary)*
* [ServBay](https://www.servbay.com/) – Local web stack with multi-runtime support, central AI gateway, and an MCP server for AI coding agents. *(Freemium / Pay once · Proprietary)*
* [AMPPS](https://ampps.com/) – Softaculous-powered local stack enabling one-click installation for hundreds of CMSs and web apps. *(Freemium · Proprietary)*
* [Laravel Herd](https://herd.laravel.com/) – Ultra-fast, native PHP development environment shipping with Nginx, dnsmasq, and Node.js. *(Freemium / Pay once · Proprietary)*
* [MAMP](https://www.mamp.info/en/windows/) – Standard local server package for Windows and macOS offering Apache, Nginx, PHP, and MySQL. *(Freemium · Proprietary)*
* [Local WP](https://localwp.com/) – Streamlined GUI development tool tailored for WordPress with one-click SSL and live demo links. *(Freemium · Proprietary)*
* [DevKinsta](https://kinsta.com/devkinsta/) – One-click WordPress local development tool with Nginx, MariaDB, local email tools, and direct Kinsta deployment. *(Freemium · Proprietary)*
* [Devilbox](https://devilbox.org/) – Highly customizable, multi-container Docker stack for local PHP and web development. *(Free · Open Source)*

## Container & Virtualization Tools

* [Docker Desktop](https://www.docker.com/products/docker-desktop/) – Desktop container management platform for building and running isolated local services. *(Freemium · Proprietary)*
* [OrbStack](https://orbstack.dev/) – Fast, lightweight, and low-resource macOS alternative to Docker Desktop. *(Freemium · Proprietary)*
* [Podman Desktop](https://podman-desktop.io/) – Open-source, daemonless container management tool compatible with Docker workflows. *(Free · Open Source - Apache-2.0)*
* [Colima](https://github.com/abiosoft/colima/) – Minimalist container runtime for macOS and Linux supporting Docker and Kubernetes. *(Free · Open Source - MIT)*
* [Vagrant](https://www.vagrantup.com/) – Declarative CLI tool for managing reproducible virtual machine environments. *(Free · Open Source - BSL-1.1)*

## Modern Database Management Tools

* [TablePlus](https://tableplus.com/) – Native, fast GUI client with inline editing for relational and NoSQL databases. *(Freemium · Proprietary)*
* [DBeaver](https://dbeaver.io/) – Universal multi-platform database administration tool supporting JDBC databases. *(Free · Open Source - Apache-2.0)*
* [Beekeeper Studio](https://www.beekeeperstudio.io/) – Modern, privacy-focused SQL editor and database manager. *(Freemium · Open Source - GPL-3.0)*
* [HeidiSQL](https://www.heidisql.com/) – Fast Windows-native client for MariaDB, MySQL, PostgreSQL, and SQL Server. *(Free · Open Source - GPL-2.0)*
* [phpMyAdmin](https://www.phpmyadmin.net/) – Classic web-based administrative interface for MySQL and MariaDB. *(Free · Open Source - GPL-2.0)*
* [Adminer](https://www.adminer.org/) – Single-file, lightweight alternative to phpMyAdmin. *(Free · Open Source - Apache-2.0 / GPL-2.0)*
